# 两台 Mac 连接 AgentRoom

两台 Mac 都安装新版 AgentRoom，并登录可互通的 Tailscale 网络。每台机器保留自己的账号、聊天和联系人数据；连接后可以看到来源设备开放的 Agent 联系人，把它们加入私聊或群聊。

## 提供联系人

1. 打开“设置 → 连接 → 共享这台 Mac”。填写设备名称，选择检测到的 Tailscale 地址和允许对方看到的联系人，点击“开启设备共享”。
2. 点击“显示连接信息 → 复制连接信息”，将它交给你信任的另一台 Mac。
3. 共享只提供选定联系人的名称、简介、配置可用状态和运行数量。人的联系人、外部访客、历史群聊内部角色、原有聊天、记忆、角色指令、文件与服务登录不进入目录。旧共享选择中残留的内部角色也不会发布；原群聊记录保留。

本机 Codex、Claude Code、Pi 联系人支持独立的跨设备聊天，沿用来源机器的角色配置与 CLI 登录。每个请求使用独立执行记录，关闭 AgentRoom 创作工具入口；CLI 仍有其原有权限和额度。个人服务或工具联系人暂时只展示目录，界面说明需在来源设备聊天；它们尚无独立远端会话隔离验收。

## 使用联系人

1. 打开“设置 → 连接 → 其他设备 → 添加设备”。
2. 点“粘贴连接信息”，用系统粘贴填入复制的内容；也可以分别填写设备地址和令牌。点“添加设备”。
3. 在联系人中找到带有来源设备名称的伙伴，即可私聊或加入群聊。

设备地址为 `http://100.x.x.x:18750`，仅绑定本机实际拥有的 Tailscale IPv4 地址，Tailscale 提供私有网络传输。原有服务器节点的 `.ts.net` HTTPS 入口继续可用。无需开放完整个人工作区 API。需要双向访问时，两台 Mac 分别开启共享、添加对方。导入的远端联系人不会被再次转发。来源设备更改选择后，下一次检查更新目录；已撤下的联系人保留原聊天并显示不可用。主动移除的联系人不会被轮询自动加回来。

## 在线与恢复

- 每 15 秒自动检查。绿点表示来源设备可达且联系人配置可接收消息，不证明模型额度或执行一定成功。正在处理、等待审批分别显示。
- 短暂失联显示“正在重连”，距离最后成功检查满 60 秒显示“离线”，保留最后在线时间。登录或配置问题显示需要处理，不把失联推断为休眠或关机。
- 关闭窗口后仍共享；退出 AgentRoom 或机器休眠后不可访问。重连先核查原任务，不重复发送。普通停止再开启保留设备身份和令牌，原连接可以继续恢复。
- “停止共享”停止新的访问，已接受的任务保留在本机。“来自其他设备的请求”可查看执行记录。遇到未知结果先核查原任务。
- 原生 App 使用专用复制入口；粘贴通过普通文本框完成，不需要网页读取系统剪贴板的权限。令牌加密保存在本机 vault，仅明确显示或复制连接信息时返回。

## 开发验证

在各自 Mac 上运行 `pnpm open:personal:web`，浏览器会打开该 Mac 当前桌面应用持有的同一份工作区。这样可查看已经登记的来源与联系人；不另建 Web 资料、不开放完整个人 API 到网络。这个页面依赖本机 App 运行，地址随自有后台变化，使用命令重新获取即可。跨设备统一目录仍按[目录设计](../superpowers/specs/2026-11-13-unified-agent-directory-design.md)推进，当前逐客户端登记不等于所有客户端已经订阅统一注册表。

`node --test apps/personal/server/desktop-sharing.test.mjs apps/personal/server/remote-nodes.test.mjs apps/personal/server/device-network.test.mjs` 验证真实 HTTP、任务去重、联系人隔离、停启恢复、权限与状态过期。构建前端后运行 `node dev/peer-devices-acceptance.mjs` 验证两个隔离实例的完整界面；正式证据用 `AGENTROOM_EVIDENCE_DIR` 指向托管产物目录。本机双实例、真实跨 Mac 传输和实际安装包验收分别记录。
