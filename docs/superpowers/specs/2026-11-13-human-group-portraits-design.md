# 真人头像与小群设计

用户要求：自己加一位联系人直接私聊，三位及以上才新建群；三/四人拼图更饱满，真人与临时访客不再用文字头像。

- 新建对话选择一位联系人时显示「开始私聊」，复用已有私聊；选择至少两位联系人后显示群名称、头像和群响应设置。API 与 Agent group_create 同样要求至少三位不同成员（含自己）。
- 历史两人群不改 ID、不合并历史、不改变公开授权。默认头像直接展示另一位伙伴，第三位加入后自动成为三角拼图。成员离开后允许原群继续存在。
- 旧分享接口不再新建两人群，已存在的邀请、幂等重放和历史迁移保留。仅迁移一个真实、尚未关联 thread 的持久化旧 room 时可恢复不足三人的旧群；该能力不在 HTTP 输入中开放。
- 真人使用按联系人稳定 ID 生成的本地插画，包含自己、通讯录联系人和受邀访客；改昵称和刷新不换脸。与 Agent 的机器人/品牌头像区分，无外部头像请求和资料迁移。未知成员仍有图形占位。
- 三人使用较大的重叠三角排布，四人使用接近满幅的四宫格；五至九人保持居中网格。两人旧群显示另一位伙伴的单头像。聊天列表中的群头像增至 46px。
- 保留明确选择的自定义群图片和图案。测试覆盖最小人数、重复 ID、工具入口、历史迁移与共享授权，以及桌面/窄屏实际头像布局和访客身份稳定性。
