# 来房间玩：无需账号的 Agent 邀请

> 历史设计。GET-547 已按新 Roo 身份、统一审批和自动成员拼图适配；当前行为以 [迁移台账](../../migrations/agentstudio-merged-features.md)、API 与客户端合同为准。

用户已明确要求直接实现，沿用上一轮邀请研究，并增加数字分身、旅行与共同创作三个可玩的案例。本轮自行完成设计选择，不再增加方案确认环节。

## 体验

桌面导航增加“来玩”入口；群聊也可从分享按钮进入。主人挑一种玩法，选择本机 Agent，审核并编辑公开背景和分身说明，再生成邀请。不会自动共享原聊天、角色私密指令、个人记忆或第三方账号。可主动将当前聊天选定的文本带入预览，发布动作仍由主人决定。

三个场景：小熊会客厅（明确为 AI 分身，聊天与破冰问题）；下一站去哪儿（共同选旅行风格、清单和旅行笔记）；一起造点东西（共同清单、创作便笺、Agent 讨论）。案例提供可编辑的合成种子，不能假装已有真实参与者或完成工作。

访客打开链接，先看到标题、主人提供的背景、Agent 身份、参与范围与期限；填昵称并点“进来一起玩”，同一次操作记录接受并建立独立身份。昵称不证明真实身份。进入后能聊天、投票、勾选清单和共同编辑笔记；移动端聊天和计划分栏切换。主人有相同讨论视图，另有复制链接、访客移除、关闭房间。共享笔记可下载为 Markdown，内容是共同保存的实际状态。

视觉采用明亮的旅行手册和邀请卡：天空底色 #eef6ff、墨色 #183244、蓝 #305bdf、柠檬黄 #f8db65、珊瑚 #ff967d、薄荷 #bee6d2。中文 PingFang / 系统字体，标题紧凑有趣；图案和情境放在案例卡，讨论区安静。减少动态效果设置、键盘焦点、390px 布局必须可用。没有虚构用户、计数或后台执行。

## 架构与选择

保留个人 IPC / 回环 API 和设备分享原边界。新增只监听回环的访客 HTTP 服务，仅有房间白名单接口和独立网页；使用 cloudflared 的临时 HTTPS 中继做第一版朋友试玩。固定部署可由受信宿主注入公共 origin；UI 不允许任意代理目标。临时地址会变化且无持续可用保证，不假称生产托管。使用轮询，避免 Quick Tunnel 不支持 SSE。

房间、参与者、请求和共同状态保存在当前 PersonalStore 的独立 kind 中。只有主人明确发布的 brief / persona 和本房间消息、便笺、清单进入模型。原个人资料不参与。访客不接触个人工作区 API、设备令牌、后台路径、CLI 配置或角色私密指令。共享 Agent 只选择 Codex / Pi 本地执行：借用现有 ToolSessions 的受控执行，禁用继承工具，只提供本房间只读工具；不开放 shell、浏览器、文件、连接器或外部写入。不能建立该能力边界时失败关闭。

邀请能力为 256 位随机值，密文保存于原 vault，数据库保存摘要和引用，URL fragment 传递。访客会话是独立 HttpOnly SameSite cookie，服务端只存摘要；会话、房间、到期和移除每次检查。房间关闭使所有已发会话失效，取消在途模型并阻止晚结果公开。重启中的模型任务标为中断，禁止自动重发。默认 24 小时、5 位访客、全房间最多 30 次 Agent 调用；正文、队列和输出有硬上限。一位访客同一时间只提交一次运行，宿主串行执行访客请求。请求 clientId 去重且正文不可变，投票与清单按身份写入，便笺使用版本检查避免覆盖。

## 范围和验收

本次交付真实持久群讨论、共同状态与模型回复。共同创作指讨论、清单、共同便笺和导出；不宣称具备生成程序的安全执行或线上部署能力。付款、预订、邮箱和私人资料授权不进入此访客版本。

验收覆盖真实 HTTP、跨房间隔离、接受与幂等、配额、移除、到期、关闭中执行、重启恢复、并发编辑、恶意输入、私有 API 拒绝、token 去敏；浏览器验证三个案例、双访客状态同步、移动端、失败恢复。独立安全审查和适用 CI 后合并；单独记录本机模型和临时公网链路是否验收通过。
