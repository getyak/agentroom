# AgentRoom 0.2.0-alpha.2

Open **联系人 → 好友** to find another person by friend code, share an invitation link or act on requests. A friend can create a card and apply from their browser. Once both sides agree, the desktop and browser can exchange text messages. Group invitations still use the group's sharing controls.

This Apple Silicon preview also includes local group assignments and Codex session continuation. The app keeps the existing bundle identifier and workspace location. Back up your workspace before using an alpha build.

The public ZIP is ad-hoc signed. macOS may block the first launch because this build is not Apple notarized. Verify `SHA256SUMS.txt` and the source revision in `release.json` before installing. See [Friends setup](../personal/friends.md) for hosting a separate service.
