# AgentRoom 0.2.0-alpha.1

AgentRoom now lives at [getyak/agentroom](https://github.com/getyak/agentroom). The independent repository preserves the AgentStudio history, license and notices.

Your first conversation is with **阿屋 Roo**, the room's guide. Roo wears the AgentRoom mascot and uses a compatible installed local assistant. The guide explains its choice and offers environment discovery, local contacts, account/device connections and role suggestions. First chat uses the selected backend; opening the app does not call a model. Existing profiles retain their data. Revisit the guide in Settings → 测试与引导.

## Download and install

Download the `macOS-arm64.zip` from [Releases](https://github.com/getyak/agentroom/releases). It is for Apple Silicon Macs. Unzip it and move AgentRoom.app into Applications. Keep your existing profile when upgrading; no data reset is required. The app retains its compatible internal AgentStudio identity.

This alpha is **ad-hoc signed and not Apple notarized**. Gatekeeper may block it; review its provenance and use macOS System Settings → Privacy & Security → Open Anyway if you choose to run it. Do not disable Gatekeeper globally. Developer ID distribution and automatic updates remain separate work.

`SHA256SUMS.txt` verifies the archive bytes. `release.json` records source revision, version, architecture and signing facts. No accounts, CLI credentials, database, local conversations or browser profiles are bundled. Codex/Claude/Pi must be separately installed and signed in for real chat. Setup actions remain available without a model.

## Reproduce

Use a clean checkout at the release tag, macOS, Node 22+ and the pinned pnpm version. Set `TMPDIR` and `AGENTSTUDIO_MAC_OUTPUT` to a task-scoped build directory with sufficient free space.

```sh
pnpm install --frozen-lockfile
pnpm --filter @agentstudio/core build
pnpm --filter @agentstudio/desktop build
AGENTSTUDIO_MAC_SIGN_IDENTITY=- pnpm package:mac
node dev/release-mac.mjs "$AGENTSTUDIO_MAC_OUTPUT"
```

Before upload, set `AGENTSTUDIO_PACKAGED_APP` to the absolute bundle path and run `node dev/agentroom-acceptance.mjs --native`. Build success and synthetic acceptance do not establish another person's login, device connectivity or Apple notarization.
